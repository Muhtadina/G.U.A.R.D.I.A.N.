Research & Development / Machine Learning

From observation
to prediction.

A modular machine learning pipeline for multimodal driver intelligence. G.U.A.R.D.I.A.N. combines facial expression analysis, temporal body-movement recognition and predictive vehicle-state modelling to investigate how potentially unsafe situations can be identified and anticipated.

Facial recognition Temporal learning Predictive intelligence TensorFlow / Keras
Our research objective

Move beyond isolated detections. Learn from visual and vehicle observations over time, then provide evidence-based inputs to a separately validated safety decision layer.

01 / Pipeline overview

Three intelligence components.
One connected system.

Each component has a distinct learning objective, dataset, training process and evaluation strategy. Models remain modular so they can be compared and improved independently.

01

Facial expression recognition

Classify visible facial expressions from labelled images. MobileNetV3 is the primary candidate; EfficientNet-B0 provides a comparative benchmark.

02

Driver body behaviour

Extract pose-based movement features from video sequences and compare temporal models to identify defined movement patterns.

03

Predictive vehicle intelligence

Investigate a Recurrent State-Space Model (RSSM) that learns how driver and vehicle states evolve under observations and control actions.

Why this branch? Facial images provide visual expression cues. The model outputs class probabilities, not a diagnosis of stress, intoxication, alertness or driving fitness.
03 / Vision branch B

Temporal body-movement
recognition.

Driver behaviour is temporal. The pipeline therefore extracts pose sequences and movement dynamics instead of treating each video frame as an independent classification problem.

Model comparison / Temporal learning

Video-to-sequence learning

Processed body-movement data will be inspected first. The seven genuine driver recordings will then serve as a separate real-world dataset for validation and further development.

Open processed body-movement dataset ↗
Sequence-based
Video and annotation auditInspect formats, frame rates, labels, recording identities, duration and class distribution.
Frame sampling and pose extractionUse MediaPipe Pose Landmarker to extract shoulders, elbows, wrists, torso and relevant landmarks.
Feature engineeringNormalize coordinates; calculate joint angles, displacement, velocity, acceleration and movement frequency.
Temporal window generationCreate fixed-length, timestamp-aware sequences and attach verified behaviour labels.
Model comparisonTrain candidate architectures on identical driver-wise splits and compare generalization.
1D CNNBaseline for local temporal patterns in engineered features.
TCNStrong candidate for temporal patterns using causal, dilated convolutions.
GRURecurrent sequence-learning alternative with a compact gating structure.
LSTMRecurrent baseline for learning sequential dependencies.
CNN-LSTMHybrid experiment where frame-level spatial features or pose representations are encoded before temporal learning.
Random Forest / XGBoostTraditional ML baseline using engineered movement statistics. Helps determine whether deep learning adds measurable value.
Why this branch? A movement pattern cannot be understood reliably from one frame alone. Temporal features help describe how posture and movement change over time. Labels must describe observable actions, not inferred psychological diagnoses.

Data integrity: split by driver or original recording before generating overlapping windows. Never distribute adjacent or overlapping windows from the same recording across training and test sets.

04 / Predictive intelligence

World Model:
learning how states evolve.

The World Model is a proposed advanced research component. It extends the system from current-state recognition toward predicting how driver and vehicle conditions may evolve.

Proposed / RSSM-inspired

Recurrent State-Space Model

An RSSM learns compact latent representations and temporal dynamics. Its predictions can be conditioned on previous observations and actions.

  • Encode driver and vehicle observations.
  • Maintain a latent representation of system state.
  • Predict future latent states and observations.
  • Evaluate prediction error and possible risk indicators.
  • Explore action-conditioned future scenarios.
Multimodal observationsFacial probabilities · Pose features · GPS speed · Acceleration
↓
Observation encoderTransform synchronized observations into latent features
↓
RSSM latent dynamicsDeterministic recurrent state + stochastic latent state
↓
Future-state predictionEstimate evolving driver and vehicle state
Prediction errorMeasure deviation between predicted and observed state
↓
Predictive decision supportEvaluate possible future conditions and candidate actions
↓
Independent safety controllerValidated limits · actuator constraints · manual override
Safety boundary: The World Model will not independently command real vehicle braking. Predictive outputs are advisory until validated; deterministic, fail-safe control logic remains responsible for hardware actions.
Data requirement: A useful action-conditioned vehicle World Model requires synchronized observations, control actions and resulting states. Static facial images and driver videos alone cannot teach the model how a vehicle responds to braking or acceleration.
05 / System integration

From model outputs

Independent models produce evidence and predictions. A separate fusion and safety layer combines them with vehicle telemetry before any alert or hardware response.

↓

Local vehicle response

Driver alerts · Display · Buzzer · Indicators · Simulated actuator control

Immediate safety alerts and protective limits must continue locally even if cloud connectivity is lost. The predictive model supplements, rather than replaces, deterministic safety controls.

06 / Experimental methodology

How we determine
what works.

Architecture selection will be evidence-based. No model is considered successful until its performance, generalization and deployment cost have been measured.

Research componentEvaluation criteriaSelection objective
Facial CNNsMacro F1, per-class recall, confusion matrix, calibration, latencyReliable expression classification with practical inference cost
Temporal modelsMacro F1, subject-wise generalization, false alerts, latencyRecognize defined movement patterns across unseen recordings
World ModelNext-state prediction error, rollout stability, calibration, action-conditioned prediction errorDetermine whether learned dynamics improve predictive decision support
Integrated systemEnd-to-end latency, synchronization, reliability, failure handlingDemonstrate robust local operation and safe decision flow

Dataset splits must be established at the original subject/recording level before frame extraction, augmentation or overlapping-window generation. Report uncertainty and dataset limitations alongside performance.
