The Project

Main Goal

G.U.A.R.D.I.A.N. aims to build a secure, edge-AI driver monitoring and fleet management system for Bangladesh Transportation. The system is designed to identify observable risky driver states and behavior in real time, relate them to vehicle motion, support timely intervention, minimize continuous raw-video transmission, and securely synchronize relevant metadata.
Senior Design II

10-Week Plan

Phase 01 — Foundation & Data Collection

Weeks 1–2
  • Finalize face detector.
  • Submit NSU IRB request.
  • Begin BRTC/BSPMS institutional contact.
  • Arrange mini camera and collect 3–5 driver recordings and metadata.

Phase 02 — Baseline Models & Dataset

Weeks 2–4
  • Train drowsiness and emotion models using existing YawDD, FER2013, RAVDESS, and WESAD data.
  • Proceed without depending on real-world data collection.
  • Create an augmented dataset.

Phase 03 — Backend, Dashboard & Fusion

Weeks 3–7
  • Build dashboard skeleton.
  • Build backend structure.
  • Develop moderator interface.
  • Integrate vehicle motion sensors.
  • Build the motion-residual fusion model using real or simulated telemetry as available.

Phase 04 — Deployment, Validation & Finalization

Weeks 7–10
  • Complete dashboard frontend.
  • Deploy and test on-device inference.
  • Conduct accuracy testing and end-to-end system integration.
  • Finalize report, demo rehearsal, and pitch preparation.

Week 01 — Facial landmark & EAR work
