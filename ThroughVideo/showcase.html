02 / Methods

Calculations and implementation

A. Eye Aspect Ratio (EAR)

For six eye landmarks, two vertical distances are compared with the horizontal eye width. This helps quantify whether the eye appears open or closed.

EAR = (‖p₂ − p₆‖ + ‖p₃ − p₅‖) / (2 × ‖p₁ − p₄‖)

The distance function uses Euclidean distance. Landmark ordering must match the selected eye contour. Thresholds should be calibrated and evaluated across users, lighting conditions, and camera positions.

feature_extractor.pyExisting function
def calculate_ear(landmarks, eye_points):
    p1 = landmarks[eye_points[0]]
    p2 = landmarks[eye_points[1]]
    p3 = landmarks[eye_points[2]]
    p4 = landmarks[eye_points[3]]
    p5 = landmarks[eye_points[4]]
    p6 = landmarks[eye_points[5]]

    vertical_1 = distance(p2, p6)
    vertical_2 = distance(p3, p5)
    horizontal = distance(p1, p4)

    if horizontal == 0:
        return 0.0

    return (vertical_1 + vertical_2) / (2.0 * horizontal)

B. Shoulder-line tilt

The detector calculates the orientation of the line joining the left and right shoulders, then normalizes the result to the range −90° to +90°.

θ = degrees(atan2(y₂ − y₁, x₂ − x₁))

This describes shoulder-line orientation in the image. It is not an arm-raising angle. Image coordinates increase downward, so the sign may differ from conventional Cartesian diagrams.

pose_detector.pyCurrent calculation
dx = x2 - x1
dy = y2 - y1

shoulder_angle = math.degrees(
    math.atan2(dy, dx)
)

if shoulder_angle > 90:
    shoulder_angle -= 180
elif shoulder_angle < -90:
    shoulder_angle += 180

C. Upper-arm elevation relative to torso

The upper-arm vector runs from shoulder to elbow. The torso reference vector runs from shoulder to the same-side hip. The angle between these vectors estimates the arm's position relative to the torso.

θ = arccos[(a · t) / (‖a‖ × ‖t‖)]
feature_extractor.pyAdded function
arm_x = elbow[0] - shoulder[0]
arm_y = elbow[1] - shoulder[1]

torso_x = hip[0] - shoulder[0]
torso_y = hip[1] - shoulder[1]

arm_length = math.hypot(arm_x, arm_y)
torso_length = math.hypot(torso_x, torso_y)

if arm_length == 0 or torso_length == 0:
    return None

dot_product = arm_x * torso_x + arm_y * torso_y
cosine = dot_product / (arm_length * torso_length)
cosine = max(-1.0, min(1.0, cosine))
angle = math.degrees(math.acos(cosine))
return angle

Idealized upright reference: arm down ≈ 0°, arm horizontal ≈ 90°, arm overhead ≈ 180°. Camera viewpoint, torso lean, occlusion, and landmark error can change the observed values.

03

Methods & Implementation

Pose detection pipeline

  1. Capture a frame from the local webcam using OpenCV.
  2. Convert the frame from BGR to RGB and wrap it as a MediaPipe image.
  3. Run MediaPipe Pose Landmarker in video mode with a monotonically increasing timestamp.
  4. Read the shoulder, elbow, and hip landmarks, and check landmark visibility before calculating features.
  5. Draw the selected landmarks and connections on the frame for visual inspection.

Arm-angle calculation currently under review

The helper function builds an arm vector from shoulder to elbow and a torso-reference vector from shoulder to hip. It then uses the dot product to calculate the angle between those vectors.

arm_x = elbow[0] - shoulder[0]
arm_y = elbow[1] - shoulder[1]

torso_x = hip[0] - shoulder[0]
torso_y = hip[1] - shoulder[1]

arm_length = math.hypot(arm_x, arm_y)
torso_length = math.hypot(torso_x, torso_y)

dot_product = arm_x * torso_x + arm_y * torso_y
cosine = dot_product / (arm_length * torso_length)
cosine = max(-1.0, min(1.0, cosine))
angle = math.degrees(math.acos(cosine))
Interpretation note: The code above calculates the unsigned angle between two vectors. The returned angle should be between 0° and 180°; the precise mapping to “arm down,” “horizontal,” and “overhead” depends on the chosen reference vector and coordinate geometry. The current implementation still needs a controlled test and possible correction.

Existing feature helper: Eye Aspect Ratio

The feature-extraction module also includes a helper for Eye Aspect Ratio (EAR), which compares vertical eye-landmark distances with the horizontal distance between eye corners. EAR can support blink or eye-closure analysis after its landmark mapping and thresholds are validated for the chosen model and use case.
